# annotepage

This package keeps the name. The tool is published under two other names:

- [annotepage-mcp](https://www.npmjs.com/package/annotepage-mcp): what an assistant uses to read and answer review notes. From a terminal: `npx -y -p annotepage-mcp annotepage open`
- [annotepage-client](https://www.npmjs.com/package/annotepage-client): the script a site loads so reviewers can annotate its pages.

Site: [annotepage.com](https://annotepage.com) · Source: [github.com/tuxo83/annotepage](https://github.com/tuxo83/annotepage)

Running `npx annotepage` prints these two commands and exits. It runs nothing else and reaches no network.
