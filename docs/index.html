How you install it — the quick way

Several ways in. This is the fastest: the free shared server, no account.

  1. 01 You paste one tag

    At the end of <body>. Nothing to build, no account. Once it is there, it works. 

    <script src="https://cdn.jsdelivr.net/npm/annotepage-client@2/dist/annotepage.js"
        data-server="https://api.annotepage.com/api.php"
        data-project="7Qb1kZ3xNvA9dLpEqKf2Zt"
        defer></script>

  2. 02 You plug in your assistant

    Two commands, once, on your machine — and the same key, in its configuration file. 

    npm install -g annotepage-mcp
claude mcp add annotepage -- annotepage-mcp

  3. 03 You keep the key

    The project’s encryption key — the tool calls it the salt. Your reviewers each paste it once; lose it and the notes go with it. 

    JavaScript is off — the client’s setup screen does the same.

    Project id —, derived from it and safe to publish.

    Lose the key, lose the notes. No recovery, no escrow, no rotation. Share it with your reviewers the way you share a password, and keep it there — what that costs, and what the server can still see.
