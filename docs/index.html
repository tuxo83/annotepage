Someone marks what is wrong. An assistant fixes it, replies with what it measured, and stamps the version.

Nothing to install on a server. Notes go to a free shared one, open to everybody — or to your own PHP directory if you would rather keep them.

How you install it

One tag at the end of <body>. Nothing to build, nothing to import, no account. Everyone who opens the page can annotate it.

the finished tag 
<script src="https://cdn.jsdelivr.net/npm/annotepage-client@2.0.1/dist/annotepage.js"
        integrity="sha384-VBUfe2CFvh85WRBCH1/uKse1O2wauw3at7B9gGC2fC8Y/sG03p9bZABq3MyUDbKE"
        crossorigin="anonymous"
        data-server="https://api.annotepage.com/api.php"
        data-project="7Qb1kZ3xNvA9dLpEqKf2Zt"
        data-version="1.4.13"
        defer></script>

Nothing in it is yours to fill in. data-server is the shared server; point it at your own instead if you prefer. The id was derived in your browser from the salt below.

Salt lost = notes lost. No recovery, no escrow, no rotation. Keep it where your team keeps its passwords — what that costs.

And on the assistant side

An MCP server and a command line, over the same notes.

plug it in 
npm install -g annotepage-mcp
claude mcp add annotepage -- annotepage-mcp
the commands above 
annotepage open
annotepage reply <id> <text>
annotepage resolve <id> <version>
