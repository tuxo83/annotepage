Put it on a page

01

Paste this tag

At the end of <body>. The id below was made in your browser; only data-server is yours.

the finished tag 
<script src="https://annotepage.com/annotepage-client-2.0.1.js"
        integrity="sha384-VBUfe2CFvh85WRBCH1/uKse1O2wauw3at7B9gGC2fC8Y/sG03p9bZABq3MyUDbKE"
        crossorigin="anonymous"
        data-server="https://your-server.example.com/annotepage/api.php"
        data-project="7Qb1kZ3xNvA9dLpEqKf2Zt"
        data-version="1.4.13"
        defer></script>

The server is then told about the project in three lines. Not the salt.
