How you install it — the quick way

Several ways in. This is the fastest: the free shared server, no account.

ⓘ Open mode. Anyone who can open your page can read these notes and add their own.
Want them private? See the secure way.

  1. You paste one tag

    At the end of <body>, on the pages you want annotated. 

    <script src="https://cdn.jsdelivr.net/npm/annotepage-client@2/dist/annotepage.js"
        data-server="https://api.annotepage.com/api.php"
        data-project="7Qb1kZ3xNvA9dLpEqKf2Zt"
        defer></script>

  2. You plug in your assistant

    Two commands, once, on your machine. 

    npm install -g annotepage-mcp
claude mcp add annotepage -- annotepage-mcp

  3. You ask it to read them

    One sentence, with the address of your site.

    ✻ Pondering…

    ❯ connect to staging.example.com with annotepage and fix what the reviewers flagged
