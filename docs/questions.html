Questions people ask

Everything you always wanted to know — including the two or three you would rather learn here than later.

The key

What if I lose the key?

In secure mode, the notes go with it. There is no recovery and no rotation — the key is what decrypts them, and the server has never had it. In open mode the key is written in the tag, on a page anybody can read, so it cannot be lost.

The key

Can I let someone read the notes without writing any?

No. The key reads and writes; there is no reader-only role.

The key

Where does the key come from?

Your browser draws it, on the install page, and sends it nowhere. The project id in the tag is derived from it and does not lead back to it — the server recognises that id, it never issues one.

The notes, and what the server holds

What does the notes server see?

Counts, times, sizes, IP addresses and your domain. Never your paths, never your text — in secure mode it cannot read a line it stores.

The notes, and what the server holds

Is there an account, a moderator, a way to delete a note?

None of them, and no notification either. A project is a key and the notes under it.

The notes, and what the server holds

Can I switch from open to secure later?

For new notes, yes: change the tag. The notes already written keep the mode they were written in, and nothing converts them.

The notes, and what the server holds

Can the page sit behind a login?

Yes. Neither the notes server nor the assistant ever opens it: the MCP talks to the notes API and to nothing else, and the page is opened by the reviewers’ own browsers, which are already signed in.

The tag

Can I load it as a module?

No, and it fails quietly. The client reads document.currentScript to find its own settings, and a type="module" script does not have one: nothing appears, and nothing is logged.

The tag

What if I pin the script with a wrong integrity digest?

The browser refuses the file and the tool simply does not appear. Nothing on the page says why. The install page writes the digest for you when you ask for a pinned tag.

The tag

My site sets a Content-Security-Policy. What do I need?

Two directives. script-src must allow wherever the client is served from, or it never loads; connect-src must allow your notes server, or fetch fails and the tool stands down in silence, as if nothing had been configured. style-src usually needs nothing: the stylesheet goes in as a constructed sheet, which is not an inline sheet in the policy’s sense.

The tag

Can I try it on my own machine?

Yes: localhost is a secure context, so the browser has the crypto it needs. But never declare localhost:3000 in a server’s list of domains — that name belongs to every machine on earth, so declaring it lets any of them write to your project.

What it costs

Is it free?

Yes, and it is MIT. The shared notes server at api.annotepage.com is free to use with nothing to install; running your own is free too, and that is the whole list.

What it costs

Do I have to use your server?

No. One PHP file installs your own, and the install page takes you through it. The tag names whichever one you run.
