The server, in Node

Your own app, not PHP — a library you embed, or an app you run.

  • No PHP
  • Same browser client
  • End‑to‑end encrypted · no key on the server
  • SQLite · interchangeable with PHP

Run it

npx annotepage-server --project <id> --report-statistics false

--help for the rest.

Embed it

import { createServer } from 'annotepage-server';
import { SqliteStore } from 'annotepage-server/stores/sqlite';
import { nodeListener } from 'annotepage-server/adapters';

const api = createServer({
    store: new SqliteStore({ file: './data/notes.sqlite' }),
    projects: { '<id>': { mode: 'encrypted' } },
    reportStatistics: false,
});
app.use('/annotepage/api', nodeListener(api));
