The library & app, in Node

Embed it in the app you already run, or launch it on its own. No PHP.

  • Embed it

    In the app you already run.

    A fetch handler — Express, Fastify, Bun, Deno, Workers.

    import { createServer } from 'annotepage-server';
import { SqliteStore } from 'annotepage-server/stores/sqlite';
import { nodeListener } from 'annotepage-server/adapters';

const api = createServer({
    store: new SqliteStore({ file: './data/notes.sqlite' }),
    projects: { '<id>': { mode: 'encrypted' } },
});
app.use('/annotepage/api', nodeListener(api));

  • Run it

    On its own, from a terminal.

    --help for the options.

    npx annotepage-server --project <id>

The browser client and the wire format do not change.
