Install the app on the server

1. Upload one PHP file anywhere under your web root. 

https://raw.githubusercontent.com/tuxo83/annotepage/main/server/annotepage-install.php

2. Open it and press its button. It fetches the rest and hashes it against the release’s MANIFEST.

3. Answer two questions. Both already carry the answer that works.

4. Paste the line it prints into the tag below, then declare your origin. 

'origins' => array('https://staging.example.com'),

PHP 7.4 and pdo_sqlite. The rest is in INSTALL.md.

<script src="https://cdn.jsdelivr.net/npm/annotepage-client@2/dist/annotepage.js"
        data-server="https://api.annotepage.com/api.php"

document.querySelector('script[data-key]')

Install the MCP on the assistant

1. In the command. The key is on the page, so there is nothing to configure. 

npm install -g annotepage-mcp
claude mcp add annotepage -- annotepage-mcp

1. In the command. The key rides in it, and never enters the conversation. 

npm install -g annotepage-mcp
claude mcp add annotepage \
  -e ANNOTEPAGE_API=https://api.annotepage.com/api.php \
  -e ANNOTEPAGE_KEY=<the key above> \
  -e ANNOTEPAGE_AUTHOR=Assistant \
  -- annotepage-mcp

2. In a file for several sites, chmod 600 and gitignored. 

"api":    "https://staging.example.com/notes/api.php",
"key":    "<the key>",
"origin": "https://staging.example.com"

3. Let the assistant write it. Easiest, and the key crosses a provider’s logs.

Then, in one sentence: 

connect to staging.example.com with annotepage and fix what the reviewers flagged

What you cannot undo

  • Lose the key, lose the notes. No recovery, no rotation.
  • The key reads and writes. There is no reader-only role.
  • The mode is settled by the tag, and never after.
  • A classic script tag, or nothing. A module leaves it silent.
  • The server sees counts, times, sizes, IPs and your domain — never your paths or your text.
  • No account, no moderation, no deletion, no notification.
  • Never declare localhost:3000 in a domain list. It names every machine on earth.
  • A wrong integrity digest fails silently.
