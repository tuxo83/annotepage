Install the app on the server

  1. Upload one PHP file

    Anywhere under your web root. Open it: its button hashes the rest against the MANIFEST. 

    https://raw.githubusercontent.com/tuxo83/annotepage/main/server/annotepage-install.php

  2. Declare your origin

    One line, and its last one goes in the tag. 

    'origins' => array('https://staging.example.com'),

  3. Keep it up to date

    Once a day. The last screen gives you this line with the real path already in it. 

    17 4 * * * php <your install>/internal/update.php >/dev/null

  4. Keep it up to date

    The installer writes a secret and shows the address once, on its last screen and nowhere else. 

    17 4 * * * curl -fsS 'https://staging.example.com/notes/api.php?action=update&token=<the secret>'

PHP 7.4 and pdo_sqlite. The installer also asks where the notes go: a file it creates and checks the web server refuses to serve, or a MySQL you already have — have its host, name, user and password to hand for that one. The rest is in INSTALL.md.

Install the tag on the site

  1. Paste the tag

    At the end of <body>.

    The key was drawn in this browser, just now, and sent nowhere.

    The id is derived from the key, in this browser, just now — the server recognises it, it never issues it. 

    <script src="https://cdn.jsdelivr.net/npm/annotepage-client@2/dist/annotepage.js"
                            data-server="https://api.annotepage.com/api.php"
                            data-key="<43 characters, drawn in your browser>"
                            defer></script>

    Where it goes, in what you use:

    index.html, Angular included

    src/layouts/*.astro

    app/layout.tsx, or pages/_document.tsx

    nuxt.config.ts, under app.head.script

    src/app.html

    app/views/layouts/application.html.erb

    your base template

    resources/views/layouts/app.blade.php

    templates/base.html.twig

    footer.php, or the wp_footer hook

  2. Hand the key over

    Each reviewer pastes it once.

    <43 characters, drawn in your browser>

    ⚠ Nothing on the page carries it. Lose this key and the notes go with it — no recovery, no rotation. Put it where your team keeps its passwords, now.

Install the MCP on the assistant

  1. Install it

    One command to install it, one to plug it into your assistant.

    The key is on the page, so that is all there is. 

    npm install -g annotepage-mcp
claude mcp add annotepage -- annotepage-mcp

  2. Give it the key

    One file, on the machine where your assistant runs.

    The address is on your tag. The key is the one your reviewers paste.

    Or let the assistant write it: easiest, and the key crosses a provider’s logs.

    One sentence, with the address of your site.

Questions people ask

What if I lose the key?
The notes go with it. There is no recovery and no rotation — the key is what decrypts them, and the server has never had it.
Can I let someone read the notes without writing any?
No. The key reads and writes; there is no reader-only role.
Can I switch from open to secure later?
For new notes, yes: change the tag. The notes already written keep the mode they were written in, and nothing converts them.
Can I load it as a module?
No, and it fails quietly. The client reads document.currentScript to find its own settings, and a type="module" script does not have one: nothing appears, and nothing is logged.
What does the notes server see?
Counts, times, sizes, IP addresses and your domain. Never your paths, never your text — in secure mode it cannot read a line it stores.
Is there an account, a moderator, a way to delete a note?
None of them, and no notification either. A project is a key and the notes under it.
Can I try it on my own machine?
Yes: localhost is a secure context, so the browser has the crypto it needs. But never declare localhost:3000 in a server's list of domains — that name belongs to every machine on earth, so declaring it lets any of them write to your project.
What if I pin the script with a wrong integrity digest?
The browser refuses the file and the tool simply does not appear. Nothing on the page says why.
